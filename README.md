# code_conversion
simple GUI application for code_conversions using python tkinter

## Folder structure
- `code_conversion.py` — main Tkinter app
- `assets/` — images used by the app (`logo.jpg` background) and screenshots (`outputCodeConversion.png`)

It will perform the following operations:
    decimal ---->  binary,
    decimal ---->  octal,
    decimal ---->  hexadecimal,
    hexadecimal ----> decimal,
    octal ----> decimal,
    binary ----> decimal
